# 🍫 Chocolate Sexy Project

Página web oficial del club **Chocolate Sexy**, desarrollada para centralizar toda la información del equipo en una única plataforma moderna, visual y accesible.

El objetivo del proyecto es crear una experiencia similar a una web deportiva profesional, donde jugadores, seguidores y visitantes puedan consultar información del club, resultados, calendario, noticias y futuras funcionalidades relacionadas con usuarios registrados (exclusivo para jugadores de equipo).

---

## ⚽ Sobre el proyecto

**Chocolate Sexy FC** nace como una plataforma web enfocada en un equipo de fútbol, desarrollada utilizando tecnologías modernas del ecosistema **SAP** y frontend web.

La aplicación busca ofrecer una experiencia limpia, rápida y responsive, inspirada en páginas deportivas y comunidades de videojuegos/wiki (estilo Dokkan wiki o Dokkan DB), permitiendo centralizar información importante del club.

Actualmente el proyecto se encuentra en desarrollo y seguirá evolucionando progresivamente con nuevas funcionalidades.

---

## 🎯 Objetivos del proyecto

### Corto plazo
- Acabar todas las vistas y controladores (los datos ahora mismo estan escritos directamente en el view)
- Que sea responsive

### Medio plazo
- Registro e inicio de sesión de usuarios (exclusivo jugadores)
- Sistema de cuentas en la nube
- Que todos los datos que se vean se vean en la pagina sea llamados desde el db
- Parsear todos los datos de la última tempora

### Largo plazo
- Usar la API oficial de instagram para mostrar los post en directo en el Main.view
- Mejorar el estilo de la página
- Publicar el proyecto
